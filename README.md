# GSD-List
GSD List

## Also in this repo

- [`GuardAggroWatch/`](GuardAggroWatch/README.md): a World of Warcraft **TBC Classic Anniversary** addon for rogues.
  It maps city guard aggro ranges and blind spots on a radar, the minimap and the world map. See its README for the
  core features and commands.
- [`RangeRing/`](RangeRing/README.md): a **TBC Classic Anniversary** addon that draws a ring around your character.
  The ring grows with the distance to your target and is colored by melee, dead zone, in range (35 yd) and out of
  range.
