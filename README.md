- [`lucas-reading-island/`](lucas-reading-island/README.md): **Lucas Reading Island**, a playful learn-to-read game for ages 4 to 6
  (letters, numbers, letter sounds, then 2 and 3 letter words) with XP, levels, stickers and research-based phonics.
  Open `lucas-reading-island/index.html` in a browser. Tests: `node tests/lucas-reading-island/run_tests.js`.

- [`GuardAggroWatch/`](GuardAggroWatch/README.md): a World of Warcraft **TBC Classic Anniversary** addon for rogues.
  It maps city guard aggro ranges and blind spots on a radar, the minimap and the world map. See its README for the
  core features and commands.
